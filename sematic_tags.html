Semantic Tags

Header

Header is used to define the header of a document or a section. It usually contains introductory content or navigational links.

Navigation

Navigation is used to define a set of navigation links. It helps users navigate through the website.

Aside

Aside is used to define content that is tangentially related to the content around it. It is often used for sidebars, pull quotes, or advertisements.

More About Details

Details is used to define additional information that the user can view or hide. It is often used for collapsible sections.

Footer

Footer is used to define the footer of a document or a section. It usually contains information about the author, copyright, or related documents.
